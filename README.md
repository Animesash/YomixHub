# YomixHub

Читалка манги и ранобэ с каталогом внешних источников — нативное Android-приложение
на **Jetpack Compose + Material 3** (Material You), тёмная тема по умолчанию,
с живыми каталогами **MangaLib**, **RanobeLib** и **HentaiLib (18+)** и общим
кэшем закладок, уведомлений и загрузок.

> 🎨 **Быстрый просмотр дизайна:** откройте [`design/yomixhub-md3-preview.html`](design/yomixhub-md3-preview.html) —
> интерактивное пиксель-точное превью экрана (412dp, вкладки, сворачиваемая верхняя панель,
> фильтры каталога и переключение Material You палитр).

---

## Источники (sources)

Каталог построен вокруг интерфейса `Source` (`data/source/Source.kt`): популярное /
новинки / поиск / детали тайтла / список глав / контент главы (текст **или** страницы).
Все три сайта семейства LibGroup работают на одном JSON API и различаются `site_id`,
поэтому их обслуживает один обобщённый клиент `LibGroupSource`
(`data/source/LibGroupSource.kt`):

| Источник | site_id | Чип / выбор |
| --- | --- | --- |
| **MangaLib** (`mangalib.me`) | 1 | чип «Манга», режим «Все источники» |
| **RanobeLib** (`ranobelib.me`) | 3 | чип «Новеллы», режим «Все источники» |
| **HentaiLib** (`hentailib.me`, 18+) | 4 | нижний лист «Источник каталога» (иконка ≡) |

- **Список/поиск** — `GET /api/manga?site_id[]=…&sort=rate&page=…` (+ `&q=…` для поиска);
- **Новинки** — `GET /api/latest-updates?page=…`;
- **Детали** — `GET /api/manga/{slug_url}?fields[]=summary&fields[]=genres&…`;
- **Главы** — `GET /api/manga/{slug_url}/chapters` (отфильтрованы ветки на модерации
  и закрытые платные главы, список разворачивается «новые сверху»);
- **Контент главы** — `GET /api/manga/{slug_url}/chapter?volume=…&number=…[&branch_id=…]`;
  текст ранобэ приходит HTML-подобной строкой с `</p>`-разделителями либо tiptap-JSON
  (оба разбираются в абзацы, Jsoup + org.json), манга/манхва — массивом `pages[]` с
  *относительными* путями картинок;
- **Сервер картинок** — `GET /api/constants?fields[]=imageServers`: выбирается сервер
  `compress`, обслуживающий текущий `site_id`, и подставляется перед путями страниц;
  полученные абсолютные URL рендерятся в читалке вертикальной лентой.

Режим «Все источники» грузит MangaLib и RanobeLib **параллельно** (`async`/`awaitAll`)
и interleav'ит результаты round-robin, так что обе ленты представлены в сетке;
поиск тоже идёт по всем выбранным источникам сразу.

API отдаёт часть маршрутов только «браузерным» запросам, поэтому клиент шлёт заголовки
`User-Agent`, `Origin`, `Referer: <сайт источника>` и `Site-Id: <id>` (как официальные
клиенты). Обложки и страницы грузятся через Coil **с заголовками конкретного источника**
(`ImageRequest.Builder.addHeader` в `CoverImage`/читалке — глобальный Referer-интерсептор
больше не нужен). Ответы кэшируются в памяти, чтобы навигация «детали → главы →
читалка → назад» не долбила API (лимит ~90 запросов/мин).

Сетевой стек: **OkHttp 4.12** + **Jsoup 1.18** + **Coil 2.7**; JSON — встроенный `org.json`.

**Firebase**: подключён плагин `com.google.gms.google-services` 4.5.0 (версии — в
`gradle/libs.versions.toml`), конфиг `app/google-services.json` (пакет
`com.yomixhub.android`, проект `yomixhub`). Зависимости берутся из BoM 34.18.0:
`firebase-auth` + `firebase-firestore` (артефакты с суффиксом `-ktx` устарели и
больше не публикуются — Kotlin-расширения входят в основные модули) и
`play-services-auth` 21.2.0 для входа через Google.

**Аккаунт и синхронизация закладок** (карточка «Аккаунт» в настройках):
* вход через Google ID-token (legacy `GoogleSignIn` intent → Firebase Auth
  `signInWithCredential`); пока пользователь не вошёл — кнопка «Войти через
  Google», после входа — имя, e-mail, аватар и «Выйти из аккаунта»;
* закладки локально хранятся в DataStore (`BookmarksStore`) и, пока
  пользователь аутентифицирован, зеркалируются в Cloud Firestore по пути
  `/users/{uid}/bookmarks/{key}` (документ — поля тайтла + `bookmarkStatus` /
  `lastSeenChapterId` / `addedAt`);
* при входе удалённая коллекция подтягивается и сливается с локальной (union
  по ключу; статус чтения — у более новой записи, `lastSeenChapterId` —
  максимум; `Task.await()` из `kotlinx-coroutines-play-services`), слитый
  набор пушится обратно — вкладка «Закладки» бесшовно показывает общие данные;
* каждое локальное изменение (добавить/удалить закладку, сменить статус,
  обновить «прочитано до») мгновенно пишется в DataStore и, при активной
  сессии, fire-and-forget в Firestore (`BookmarkRepository`).

## Экран (главный)

```
┌──────────────────────────────────────┐
│ 21:47                       ⌾ ▮ ▮ ▮  │  status bar (edge-to-edge)
│                                      │
│                            ⌕  ⚙    │  Compact TopAppBar (без заголовка):
│                                      │  поиск + настройки
│  [Все] [Манга] [Новеллы]             │  Filter chips
│  Популярное сейчас                   │  section header
│  ┌────┐  ┌────┐  ┌────┐             │
│  │░░░░│  │░░░░│  │░░░░│             │  3-колоночная сетка карточек:
│  │MANGA│  │MANGA│  │NOVEL│          │  elevated card + 2:3 обложка +
│  ├────┤  ├────┤  ├────┤             │  chip формата в углу
│  └────┘  └────┘  └────┘             │
│  …                                   │
├──────────────────────────────────────┤
│  ▣Закладки  ▦Все тайтлы  🔔24  ⤓64% │  NavigationBar 80dp + navigationBarsPadding
└──────────────────────────────────────┘
```

Чипы переключают тип контента: «Манга» — лента MangaLib, «Новеллы» — RanobeLib,
«Все» — каталог, выбранный в «Настройках → Источник каталога»: по умолчанию обе
ленты interleav'ятся вместе, но можно закрепить одну, включая HentaiLib
(помечен бейджем 18+). Строка поиска ищет по всем выбранным источникам.
Тап по карточке открывает экран деталей (обложка, автор, статус, жанры, описание,
закладка и статусы «Читаю / В планах / Прочитано»), оттуда — читалка: текст главы
для ранобэ или вертикальная лента страниц для манги. Ошибка сети показывает карточку
с «Повторить» и возможностью уйти на демо-каталог (реальные обложки с CDN).

## Поиск по всем вкладкам

Иконка ⌕ в топ-баре включает поиск на любой вкладке — состояние и текст запроса
общие (`YomixHubApp`), поэтому запрос «переезжает» вместе с пользователем между
«Закладками», «Все тайтлы», «Уведомлениями» и «Загрузками»:

- **Закладки / Уведомления / Загрузки** — мгновенная фильтрация по названию
  тайтла (в загрузках — и по главе) на каждый символ;
- **Все тайтлы** — тот же запрос уходит в удалённый поиск по выбранным
  источникам (с дебаунсом 400 мс), демо-каталог фильтруется локально.

## Настройки и обновления

Экран настроек (шестерёнка в топ-баре):

- **Проверить обновления** — `GET https://api.github.com/repos/Animesash/YomixHub/releases/latest`
  (`data/GitHubUpdater.kt`): тег релиза сравнивается с `BuildConfig.VERSION_NAME`
  численно (терпим `v`-префикс и разделители `.`/`-`/`_`); если вышла новая версия —
  диалог с примечаниями к релизу и кнопкой «Скачать», открывающей APK-ассет
  последнего релиза в браузере (fallback — страница релизов). Если ассетов ещё нет,
  GitHub отвечает 404 и показывается понятная ошибка;
- **Источник каталога** — тот же нижний лист выбора каталога
  (Все источники / MangaLib / RanobeLib / HentaiLib 18+).

## Закладки, уведомления и загрузки

Всё живое состояние собрано в синглтоне `data/AppState.kt` (Compose snapshot state,
без хардкода):

- **Закладки** — добавляются иконкой-закладкой на экране деталей; в библиотеке
  работают фильтры «Читаю / В планах / Прочитано» и бейдж непрочитанных глав;
- **Уведомления** — при загрузке списка глав закладки сравнивают свежие главы с
  `lastSeenChapterId`: новые превращаются в уведомления (до 5 на тайтл), тап по
  строке отмечает прочитанным; бейдж на нижней панели считает непрочитанные;
- **Загрузки** — иконка ⤓ у главы запускает настоящий fetch контента через источник
  (прогресс-тикер + финальный результат): готовые главы кэшируются и открываются
  в читалке офлайн, у ошибки есть повтор, любую запись можно удалить крестиком.
  Очередь загрузок и содержимое скачанных глав **переживают перезапуск приложения**:
  они хранятся в DataStore Preferences (`data/persistence/DownloadsStore.kt`, JSON
  поверх org.json — без аннотационных процессоров), восстанавливаются в
  `AppState.attach()` при старте; загрузки, прерванные выключением, помечаются
  как ошибочные, чтобы их можно было перезапустить.

## Приветственный диалог первого запуска

При первом запуске альфы над интерфейсом показывается Material 3-диалог
«YomixHub <версия>» с перечнем того, что уже доступно (Google-аккаунт,
облачные закладки, каталоги MangaLib/HentaiLib/RanobeLib), чекбоксом
«Больше не показывать» и кнопкой «Начать читать»
(`ui/components/WelcomeDialog.kt`). Флаг `show_alpha_welcome_dialog`
(по умолчанию `true`) хранится в DataStore
(`data/persistence/SettingsStore.kt`, хранилище `yomixhub_settings`);
MainActivity читает его асинхронно через `LaunchedEffect` и сбрасывает в
`false` только по кнопке с отмеченным чекбоксом — диалог скрывается, но
сама галочка сохраняется через `rememberSaveable` и при пересоздании
активности.

## Читалка и системные панели

Читалка прячет системную навигационную панель (`WindowCompat.getInsetsController` +
`BEHAVIOR_SHOW_TRANSIENT_BARS_BY_SWIPE`, восстановление при закрытии) — режим A;
на остальных экранах действует режим B: `NavigationBar` с `navigationBarsPadding()`
и `innerPadding` как `contentPadding` списков (детали ниже).

## Системные панели (edge-to-edge, режим B)

- `Scaffold` отдаёт `innerPadding` экранам, а их `LazyVerticalGrid`/`LazyColumn`
  используют его как `contentPadding` (объединение с дизайн-отступами через
  `PaddingValues.mergedWith`) — контент скроллится под панелями, но не обрезается;
- `NavigationBar` не имеет принудительной высоты: собственные 80dp компонента плюс
  `Modifier.navigationBarsPadding()`, собственные `windowInsets` обнулены — инсет
  применяется ровно один раз, поэтому пилюля и подписи не сжимаются при жестовой
  навигации Android 14+.

## Соответствие спецификации Material 3

| Элемент | Токен / значение |
| --- | --- |
| Navigation Bar | высота **80dp** (intrinsic), контейнер `surfaceContainer` |
| Активный индикатор | пилюля **64×32dp, r16**, `secondaryContainer` / `onSecondaryContainer` |
| Иконка «Закладки» | `Bookmark` **filled** в активной вкладке, outlined в остальных |
| Бейдж «Уведомления» | MD3-красный (`error`/`onError`) со счётчиком непрочитанных глав |
| Бейдж «Загрузки» | мини-индикатор прогресса (determinate ring 16dp) вместо бейджа |
| Top App Bar | Compact (64dp, без заголовка), иконки Search + Settings (⚙) |
| Карточки каталога | `ElevatedCard` (r12, `surfaceContainerLow`), обложка 2:3 |
| Chip формата | r6, **10sp/600**; `MANGA` → `secondaryContainer`, `NOVEL` → `tertiaryContainer` |
| Типографика | шкала M3 (Roboto): headline 28, title 16, body 14/12, label 11 |
| Тема | тёмная, dynamic color (Android 12+) либо базовая фиалетовая тоновая палитра |

## Сборка

```bash
./gradlew :app:assembleDebug
```

Требуется JDK 17+. Файл `app/google-services.json` должен оставаться в модуле
`app/` — без него плагин google-services ломает сборку. Проект использует **AGP 9** со встроенной поддержкой Kotlin
(отдельный плагин `org.jetbrains.kotlin.android` не нужен) и Compose compiler
plugin `org.jetbrains.kotlin.plugin.compose`. Версии — в `gradle/libs.versions.toml`.

Версия приложения задаётся в `app/build.gradle.kts` (`versionName`); проверка
обновлений сравнивает её с тегом последнего релиза на GitHub — публикуйте релизы
с тегами вида `v1.1` и приложенным APK-ассетом, и встроенный апдейтер предложит
их к скачиванию.

При запуске на Android 12+ без изменений применяется обоевая динамическая схема
(Material You); `YomixHubTheme(dynamicColor = false)` включает фирменную
фиолетовую палитру, использованную в HTML-превью.

## Каталог design/

- `yomixhub-md3-preview.html` — самодостаточное интерактивное превью экрана
  (обложки встроены как data-URI, три seed-палитры Material You);
- `covers/` — исходные сгенерированные обложки-иллюстрации для превью;
- `covers-web/` — оптимизированные копии (360×540) для встраивания.
